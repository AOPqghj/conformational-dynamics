# Third-party assets and terms

This repository's MIT and CC BY 4.0 grants apply only to original code and original manifest organization/annotations. They do not relicense upstream assets.

| Asset | Use | Terms / authoritative source |
|---|---|---|
| RCSB Protein Data Bank records | structure identifiers and screened records | PDB data files are distributed under CC0; see https://www.rcsb.org/pages/policies |
| UniProt records | accessions and sequences | UniProt data are CC BY 4.0; see https://www.uniprot.org/help/license |
| AlphaFold Protein Structure Database | pLDDT and predicted structures | CC BY 4.0; see https://alphafold.ebi.ac.uk/faq |
| ESM / ESMFold | embedding generation | upstream code/model terms at https://github.com/facebookresearch/esm |
| BioEMU | embedding generation | upstream code/model terms at https://github.com/microsoft/bioemu |
| MMseqs2 | homology clustering | GPL-3.0; see https://github.com/soedinglab/MMseqs2 |
| ATLAS, DynamicMPNN, PATHpre, ProMiSE, Hinge Atlas / StoneHinge | source annotations or validation | cited primary publications and their accompanying repositories/databases; users must verify the applicable record-level terms before redistributing upstream content |

The release includes only the sequence-level research manifest needed to identify and regenerate the cohort, not upstream bulk databases. Licensing for the last group is not uniformly stated in a single authoritative location; this unresolved point is disclosed rather than treated as a blanket license.
