# Third-party assets and terms

This repository's MIT and CC BY 4.0 grants apply only to original code and original manifest organization/annotations. They do not relicense upstream assets.

| Asset | Use | Terms / authoritative source |
|---|---|---|
| RCSB Protein Data Bank records | structure identifiers and screened records | PDB data files are distributed under CC0; see https://www.rcsb.org/pages/policies |
| UniProt records | accessions and sequences | UniProt data are CC BY 4.0; see https://www.uniprot.org/help/license |
| AlphaFold Protein Structure Database | pLDDT and predicted structures | CC BY 4.0; see https://alphafold.ebi.ac.uk/faq |
| ESM / ESMFold | embedding generation | MIT; see https://github.com/facebookresearch/esm |
| BioEMU | embedding generation | MIT; its vendored AlphaFold2 and ColabFold components retain Apache-2.0 and MIT terms; see https://github.com/microsoft/bioemu |
| MMseqs2 | homology clustering | MIT; see https://github.com/soedinglab/MMseqs2 |
| Hinge Atlas | validation annotations | CC BY 2.0; see https://pmc.ncbi.nlm.nih.gov/articles/PMC1913541/ |
| ATLAS | source provenance | public data portal; no blanket redistribution license is asserted, and ATLAS trajectories or annotation tables are not redistributed |
| DynamicMPNN | source provenance | public publication, repository, and Zenodo record; no blanket redistribution license is asserted, and its source archives are not redistributed |
| PathPre | source provenance | cited publication and supplementary materials; no blanket redistribution license is asserted, and its source tables or trajectories are not redistributed |
| ProMiSE | source provenance | public publication and repository; no blanket redistribution license is asserted, and its repository files are not redistributed |

The release includes only the sequence-level research manifest needed to identify and regenerate the cohort, not upstream bulk databases, trajectories, or source annotation tables.
Its CC BY 4.0 data license applies to the project-authored organization and labels, while each upstream record retains the terms listed above.
For sources without explicit redistribution terms, the release contains factual provenance identifiers and project-authored screening outcomes only.
